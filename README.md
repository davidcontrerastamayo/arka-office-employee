# arka-office-employee

This is a monorepo for the Arka Office Employee project, containing a web application built with React and TypeScript, and a mobile application built with React Native.

## Setup Instructions

### Prerequisites
- Node.js (version 14 or higher)
- npm or Yarn

### Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:davidcontrerastamayo/arka-office-employee.git
   cd arka-office-employee
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Applications
- To run the web application:
   ```bash
   cd apps/web
   npm start
   ```
- To run the mobile application:
   ```bash
   cd apps/mobile
   npm start
   ```

## Technology Stack
- **Web Application:** React, TypeScript, Tanstack Query
- **Mobile Application:** React Native
